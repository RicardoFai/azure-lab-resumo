# Azure Lab Resumo

Este repositório contém o resumo prático dos conceitos e ferramentas explorados durante o laboratório de Computação em Nuvem com **Microsoft Azure**.

---

## 📌 Conteúdo Aprendido

- **Conceitos de Nuvem:** Benefícios da nuvem pública, escalabilidade, disponibilidade e modelos de serviço (IaaS, PaaS, SaaS).
- **Gerenciamento de Recursos:** Navegação e organização de serviços no Portal do Azure.
- **Serviços Principais:** 
  - Máquinas Virtuais e Contêineres.
  - Armazenamento em Nuvem (Blob Storage).
  - Configuração de Redes Virtuais e Segurança.

---

## 🚀 Como Acessar

1. Acesse o [Portal do Microsoft Azure](https://portal.azure.com/).
2. Utilize os recursos de aprendizagem e créditos para testes práticos.
